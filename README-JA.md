# NEMESIS PACT v0.5.0 — 起動・確認ガイド

## 最初に遊ぶ

`dist/NEMESIS-PACT.html` をブラウザで開き、**Meet your nemesis** → **Get counteroffer** → 条件を読んで **Sign & enter combat**。

最初の例文は「左側に結界を置き、敵弾を遅くする。代償として増援を認める」です。初回交渉画面は英語ですが、要求文は日本語も受け付けます。ローカル版は限定したキーワードによる決定的ルールで、自然言語を自由に理解するAIではありません。

左右移動に加え、結界の円へ上下にも移動してください。左上など画面端の全域が安全になるわけではありません。円は敵弾だけを消し、マゼンタ色のレーザーや敵本体への接触は防ぎません。

## 操作

| 操作 | PC | 備考 |
|---|---|---|
| 移動 | WASD / 方向キー | First Contactでは照準・射撃は自動 |
| パリィ | E | 近くの敵弾を反射 |
| ダッシュ | Space | レーザー回避にも使用 |
| Nova | F | エネルギーを使用 |
| 契約破棄 | Q | 既存の緊急救済。契約の利点を失い敵攻撃頻度が上昇 |
| 再交渉 | R / PARLEY | 8秒後から。18秒で自動提案。署名による変更は1回 |
| 一時停止 | Esc | スマートフォンでは画面内ボタン |

再交渉中は戦闘時間が停止します。**Get counteroffer** だけでは戦闘は変化せず、**Sign amendment & resume** で新条件が適用されます。**Keep current pact & resume** は旧契約のまま再開し、変更権を消費しません。体力・ボスへの累積ダメージ・経過時間はリセットされません。

画面下の契約パネルで、実際に消した弾数と反射ダメージを確認できます。クリアまたは破棄の記憶はこのブラウザ内の回数です。敵が過去の全会話を記憶しているわけではありません。

## 旧キャンペーン

タイトルの **Full campaign** から従来の6セクター、機体選択、ルート、レリック、Expedition / Gauntlet / Classicへ入れます。First Contactは既存コンテンツの削除ではなく、新しい導入・短時間モードです。

## OpenAIの実接続

この納品物では **OpenAIを実際に呼び出していません**。実装済みのサーバー経路とテスト用応答による検証を、実モデル検証と区別してください。

Node.js 22を使用し、`npm run build` → `npm start` でローカルサーバーを起動できます。ネットワーク利用なしの試遊では設定は不要です。

実接続する場合は `.env.example` を `.env` に複製し、`AI_MODE=live`、APIキー、利用権限のあるResponses＋構造化出力対応テキストモデル、正確なOrigin、ランダムなパイロットコードを設定します。

```sh
node --env-file=.env tools/serve.js
```

契約画面の **OpenAI pilot connection / privacy** を開いてサーバーモードを選び、**APIキーではなくパイロットコード**を入力し、送信に同意してください。`dist`の単体HTMLでは接続できません。サーバーが返した公開ページを使ってください。`.env` はGitやZIPに含めないでください。

設定値をそのまま `OPENAI_MODEL=gpt-live-1` に置き換えることはできません。本サーバーは契約を生成するテキストモデル向けで、GPT-Live-1音声接続は未実装です。調査と導入設計は `docs/GPT-LIVE-1-ASSESSMENT-JA.md` にあります。
