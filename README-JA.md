# NEMESIS PACT — 起動・確認ガイド

[本番HTTPSで遊ぶ](https://nemesis-pact-live.vercel.app)。正本v0.5.0 ZIPから開発し、既存の6セクターキャンペーンを保持しています。

タイトルの **Negotiate the rules. Fight your deal.** からFirst Contactへ進みます。LOCAL RULESは認証やマイクなしで試遊できます。実モデルを使う場合は、OpenAIへの送信に同意してから、英語・日本語で入力するか **Start voice** を押してマイクを許可してください。

音声は **GPT-Live-1**、契約生成はVercel AI Gateway経由の **gpt-4.1-mini** です。音声とテキストは同じ契約検証・署名経路を使います。表示された利益と代償を読み、**Sign** を押した時だけ戦闘へ適用されます。口頭の承諾だけでは署名しません。

| 操作 | PC | 備考 |
|---|---|---|
| 移動 | WASD / 方向キー | First Contactは照準・射撃が自動 |
| パリィ | E | 近くの敵弾を反射 |
| ダッシュ | Space | レーザー回避にも使用 |
| Nova | F | エネルギーを使用 |
| 契約破棄 | Q | 契約の利点を失い、敵の攻撃頻度が上昇 |
| 再交渉 | R / PARLEY | 戦闘8秒後から、18秒で自動表示。変更は1回 |
| 一時停止 | Esc | タッチ用ボタンも用意 |

結界は円内の敵弾を消します。画面の左右全域を守るわけではなく、レーザーや敵本体は防ぎません。実際の弾消去数と反射ダメージを画面に表示します。

再交渉中は時間が止まり、署名後もHP・ボスHP・経過時間を保持します。**Keep current pact & resume** で元の契約のまま再開できます。音声は署名・取消・離脱・タイムアウトで停止します。1回45秒、1プレイ内の累計90秒（同じブラウザで新しいFirst Contactを始めると別プレイとして計算）までです。拒否・障害・予算到達時も、LOCAL RULESを選んで試遊できます。

## 検証状況

本番で実テキスト推論→署名→戦闘効果→再署名を自動操作のEdgeで検証しました。本人から初回の実音声による契約変更とボス撃破の報告も受領しました。敵の返答への割り込み・言い直し・戦闘中の音声再交渉は、本人操作では未検証です。RX 6900 XT実機上のEdge自動操作では、1280x800の各10秒測定でWebGL2が59.99fps、WebGPUが60.11fpsでした。390x844のエミュレーションは59.93fpsですが、スマートフォン実機の性能は示しません。実機スマートフォンとSafariは未検証です。[現在の検証記録](docs/VALIDATION-CURRENT.md)を参照してください。

録画はURLに `?demo=1` を付け、**Record 60s demo** を押し、ゲームタブのみを音声付きで共有します。60秒後にWebMを端末へ保存します。自動アップロードはしません。最初の録画試行でタイマーの不具合があり保存できず、修正後に実ブラウザの60秒保存テストを通しました。提出用の本人操作動画と公開URLは準備中です。

## ローカル開発と費用

Node.js 22で `npm ci`、`npm run build`、`npm start` を実行します。単体版 `dist/NEMESIS-PACT.html` は完全オフラインのLOCAL RULESです。秘密キーは `.env.example` を参考にGit対象外のサーバー環境へ設定し、チャットや公開HTMLへ載せないでください。

OpenAI直接利用は承認済み合計10ドル（検証3・公開5・審査2）、Gatewayは運用上限20ドル（検証1・公開14・審査5）を共有永続クォータで管理します。Vercel申告30ドル枠の正確な残高・有効期限は未確認です。利用量の記録と請求確定額を区別し、30ドル以内を無条件には保証しません。[運用・ロールバック](docs/OPERATIONS.md)を参照してください。
