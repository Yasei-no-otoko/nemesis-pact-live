# NEMESIS PACT v1.0.0 — 起動・確認ガイド

[本番HTTPSで遊ぶ](https://nemesis-pact-live.vercel.app)。正本v0.5.0 ZIPから開発し、既存の6セクターキャンペーンを保持しています。

v0.9.9では、コンセプト画像を基にTHE NOTARY・画面・戦場を磨き、モバイルの交渉／契約確認タブとPCのクリック操作を追加しました。公開済み59秒／60fpsの本人操作映像は改良前ビルドの検証資料です。

タイトルの **Make first contact** からFirst Contactへ進みます。LOCAL RULESは認証やマイクなしで試遊できます。実モデルを使う場合は、OpenAIへの送信に同意してから、英語・日本語で入力するか **Start voice** を押してマイクを許可してください。

音声は **GPT-Live-1**、契約生成はVercel AI Gateway経由の **GPT-5.6 Luna (gpt-5.6-luna)** です。音声とテキストは同じ契約検証・署名経路を使います。表示された利益と代償を読み、**Sign** を押した時だけ戦闘へ適用されます。口頭の承諾だけでは署名しません。

| 操作 | PC | 備考 |
|---|---|---|
| 移動 | WASD / 方向キー | First Contactは照準・射撃が自動 |
| パリィ | E | 近くの敵弾を反射 |
| ダッシュ | Space | レーザー回避にも使用 |
| Nova | F | エネルギーを使用 |
| 契約破棄 | Q | 契約の利点を失い、敵の攻撃頻度が上昇 |
| 再交渉 | R / PARLEY | 戦闘8秒後から、18秒で自動表示。変更は1回 |
| 一時停止 | Esc | タッチ用ボタンも用意 |

結界は円内の敵弾を消します。画面の左右全域を守るわけではなく、レーザーや敵本体は防ぎません。実際の弾消去数と反射ダメージを画面に表示します。

再交渉中は時間が止まり、署名後もHP・ボスHP・経過時間を保持します。**Keep current pact & resume** で元の契約のまま再開できます。音声は署名・取消・離脱・タイムアウトで停止します。1回45秒、1プレイ内の累計90秒（同じブラウザで新しいFirst Contactを始めると別プレイとして計算）までです。拒否・障害・予算到達時も、LOCAL RULESを選んで試遊できます。

## 検証状況

本番で実テキスト推論→署名→戦闘効果→再署名を自動操作のEdgeで検証しました。本人のChrome録画では、初回の左結界契約→戦闘→音声で右へ再交渉→revision 2署名→右結界への反映まで確認しました。別のiPhone 16 Pro Max録画では敵の返答中の割り込みと右への訂正を確認しましたが、訂正後の署名はLOCAL RULESでした。その後、本人がWindows版Vivaldiで訂正後のOPENAI提案とSignに成功したと報告しています（従来の本人音声経路はgpt-4.1-mini）。現行のGPT-Live-1→GPT-5.6 Lunaも、本番で割り込み・右への訂正・署名・戦闘・音声再交渉・再署名まで通しました。自動操作Edgeと合成入力音声による実API検証で、人間マイク検証とは区別します。2発の弾消去、HP・ボスHP・時間の保持、両セッションの終了を確認しました。RX 6900 XT実機上のEdge自動操作では、1280x800の各10秒測定でWebGL2が59.99fps、WebGPUが60.11fpsでした。390x844のエミュレーションは59.93fpsですが、スマートフォン実機の性能を示しません。Android、macOS Safari、最新UIの実機スマートフォン性能は未検証です。[現在の検証記録](docs/VALIDATION-CURRENT.md)を参照してください。

録画はURLに `?demo=1` を付け、**Record demo** →ゲームタブを音声付きで共有→**Stop & save**で保存します。60秒の自動停止はありません。新しい119.65秒の本人録画をDaVinci Resolveで **59秒・1920×1080・固定60fps** へ編集し、元の音声と英語字幕付きで保存しました。右への訂正、OPENAI Luna契約への署名、弾消し、音声再交渉、2回目の署名、ボス撃破が映っています。3,540フレームのデコードと主要場面の字幕・表示を確認済みです。元録画の平均58.688fpsと、書き出しの固定60fpsは区別しています。[録画・編集手順](docs/FINAL-RECORDING.md)と[新しい本人録画の検証記録](docs/validation-current/human-long/README.md)を参照してください。

THE NOTARYの返答音声が録画に入っているかは本人確認待ちです。自動文字起こしで検出されたのはプレイヤー発話のみで、敵音声の有無は断定していません。公開動画URL、ソース公開または審査員アクセスの選択も残っています。自動アップロードはしません。従来の不完全な動画と不具合記録は別の履歴として保持しています。手動録画版の223単体テスト、65秒のローカル合成録画、本番の保存・再開確認は通過しました。

## ローカル開発と費用

Node.js 22で `npm ci`、`npm run build`、`npm start` を実行します。単体版 `dist/NEMESIS-PACT.html` は完全オフラインのLOCAL RULESです。秘密キーは `.env.example` を参考にGit対象外のサーバー環境へ設定し、チャットや公開HTMLへ載せないでください。

OpenAI直接利用は承認済み合計10ドル（検証3・公開5・審査2）、Gatewayは運用上限20ドル（検証1・公開14・審査5）を共有永続クォータで管理します。Vercel申告30ドル枠の正確な残高・有効期限は未確認です。利用量の記録と請求確定額を区別し、30ドル以内を無条件には保証しません。[運用・ロールバック](docs/OPERATIONS.md)を参照してください。
