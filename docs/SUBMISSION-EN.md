## Project description

NEMESIS PACT is a browser roguelite arena shooter where negotiating with an enemy changes the rules you must survive. Players speak or type to THE NOTARY, revise proposals, inspect a Living Covenant, and explicitly sign before clauses affect combat. Beyond First Contact, six sectors offer three airframes, branching routes, upgrades, relics, and distinct bosses. GPT-5.6 Luna analyzes aggregate wave or sector telemetry at encounter boundaries and returns one bounded ease, hold, or raise suggestion. Authored modifiers change bullet speed and arrival spacing by at most 16 percent; canonical pacts remain unchanged. The campaign uses fixed autoplay input for repeatability, not an AI pilot. Deterministic rendering, synthesized music, captions, touch controls, and explicit LOCAL RULES fallback keep the experience playable without API access. A verified run covered six bosses and 18 encounters.

## Judging criteria 1 (30%) - Meaningful use of OpenAI tools

GPT-Live-1 makes spoken negotiation a playable control surface. In the verified voice path, Windows Zira synthetic player audio was sent into the real Live API and received real responses; the audio source is labeled synthetic. Players can interrupt THE NOTARY and revise terms in English or Japanese. Typed requests enter the same contract pipeline. Luna proposes authored clauses; validation rejects unsupported mechanics, and only Sign applies a displayed contract. Revision tracking invalidates superseded proposals. The campaign AI Director also proposes authored formations for explicit approval. For expedition mode, Luna analyzes bounded wave or sector telemetry. The next encounter applies at most one authored step, with bullet speed and arrival spacing capped at plus or minus 16 percent. Canonical pacts remain unchanged. If analysis is unavailable, LOCAL RULES hold the current level. Fixed autoplay is a repeatable input policy, not an AI pilot. The verified run recorded six signed Luna pacts, 18 Luna analyses, and six Live voice calls.

## Judging criteria 2 (25%) - Originality

NEMESIS PACT turns a boss encounter into a negotiated ruleset. The opponent is an adversary and the counterparty to a Living Covenant. Conversation creates choices the player must execute: protecting one flank may introduce hostile reinforcements, while stronger reflected damage can require weaker ordinary shots. A player can interrupt the speaking rival, change a request, review corrected clauses, and sign. Mid-fight renegotiation is a First Contact feature; campaign adaptive analysis occurs at wave or sector boundaries. It uses aggregate results to suggest one authored difficulty step, capped at 16 percent changes to bullet speed and arrival spacing. Fixed autoplay makes the campaign demonstration repeatable without making the model an AI pilot. The verified run traversed six bosses and 18 encounters, with difficulty moving from level 0 to 1 to 2 under authored bounds. GPT-Live-1 responses to synthetic Zira player audio add a reproducible voice interaction whose source is disclosed.

## Judging criteria 3 (25%) - Playability / Utility

The production HTTPS game is designed for desktop and mobile browsers. First Contact presents a loop: negotiate, inspect benefits and costs, sign, fight, renegotiate once, and defeat the boss. Players can type or use GPT-Live-1 voice; captions, output volume, mute, transcripts, and consent controls support accessibility. Microphone refusal, connection failure, or exhausted API allowance produces an explicit LOCAL RULES alternative. The full campaign adds six sectors, six bosses, three airframes, route choices, upgrades, relics, and adaptive encounter analysis. Wave and sector results are reviewed at boundaries before authored bullet speed or arrival spacing changes by at most 16 percent. Verified aggregate results were 242 kills, 74 parries, and 371.31 seconds of combat across 18 encounters. Fixed autoplay is disclosed as an input policy, while synthetic Zira speech sent to real Live API is disclosed as the voice source.

## Judging criteria 4 (20%) - Execution and craft

The game combines deterministic two dimensional combat with a custom WebGL2 and WebGPU renderer, without Three.js or a game framework. Procedural geometry, shaders, and synthesized Web Audio deliver self contained HTML with no imported models, font downloads, or sampled soundtrack assets. OpenAI generated concept boards guided visual refinement. The implementation separates AI analysis from deterministic authority. Signed sessions, CSRF checks, durable Redis quotas, atomic budget reservations, concurrency limits, and a kill switch protect paid endpoints. Adaptive decisions are bounded, deduplicated by run and sequence, and applied only at encounter boundaries. The verified run completed six bosses and 18 encounters, with page errors at zero; combat totals were 371.31 seconds, 242 kills, and 74 parries. Difficulty advanced from 0 to 1 to 2 within authored bounds. Voice interruption and correction were tested with synthetic Zira audio and real Live responses. The production run was edited in native DaVinci Resolve into a59-second,1080p60 submission film with original audio and English captions.
